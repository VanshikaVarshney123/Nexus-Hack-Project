## 🎯 Mandatory Features & Architectural Implementation

| Section | Requirements Met | Technical Implementation |
|---|---|---|
| **Navbar** | Logo, About, Tracks, Schedule, Prizes, Sponsors, FAQ, Register CTA, Mobile Drawer | Accessible `<nav>`, sticky backdrop blur, animated hamburger toggle with ARIA attributes. |
| **Hero** | Event name, tagline, date, venue, hybrid format, custom visual, Register CTA | CSS Grid layout, Google brand glow radial gradients, responsive SVG illustration, and a **real-time live countdown timer**. |
| **About** | Event mission, who can participate, mentorship, key metric numbers | Glassmorphic cards with responsive 3-column to 1-column grid and metric banner (36h, 500+ builders, 4 tracks). |
| **Tracks** | At least 3 categories with titles & explanations | 4 specialized tracks (Multimodal AI, Next-Gen Web, Social Impact, Cloud Systems) with **interactive category filter tabs**. |
| **Schedule** | Readable timeline with >= 4 activities and time ranges | Tabbed **Day 1 / Day 2 timeline switcher** engineered to eliminate horizontal overflow on mobile screens. |
| **Prizes** | At least 3 prize tiers with sample values clearly marked | 3 ranked tiers (Grand Champion, Runner Up, Creative Innovator) with cash/swag perks + category awards banner, labeled with sample notices. |
| **Sponsors** | At least 3 sponsor placeholders marked as sample | 4 tiered sponsor cards (CloudSphere AI, DevStream Global, PixelForge Labs, NextHacker Hub) labeled with sample badges. |
| **FAQ** | Common queries answered | Accessible, keyboard-friendly accordion with smooth expand/collapse. |
| **Final CTA** | High-conversion prompt with date reminder | Gradient banner with countdown reminder and modal trigger. |
| **Footer** | Community identity, quick links, ethics disclaimer, social links | Multi-column responsive layout with GDG attribution and ethical sample notices. |
| **Demo Modal** | Client-side validation & demo notice | Accessible `<dialog>` modal with RFC-compliant email regex, required fields, and live pass preview. |

## 🛠️ Tech Stack & Compliance

* **HTML5**: Semantic elements (`<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<footer>`).
* **CSS3**: Custom CSS custom properties (Variables), Flexbox, CSS Grid, Glassmorphism, smooth animations, and zero-overflow media queries.
* **JavaScript**: Pure Vanilla ES6+ (no external dependencies, instant load times, zero build steps).
